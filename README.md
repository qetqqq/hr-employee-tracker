Учёт сотрудников

Веб-приложение для ведения списка сотрудников: просмотр, поиск, фильтрация, добавление, редактирование и увольнение.

Стек

- **Backend:** Node.js, Express
- **База данных:** SQLite
- **Frontend:** HTML, CSS, JavaScript

Запуск

1. Скачать или склонировать репозиторий.
2. Установить зависимости: `npm install`
3. Запустить сервер: `npm start`
4. Открыть в браузере: `http://localhost:3000`

Возможности

- Просмотр списка сотрудников и статусов (`Работает` / `Уволен`).
- Поиск по ФИО и фильтрация по отделу и должности.
- Добавление новых сотрудников с проверкой полей и масками для телефона и паспорта.
- Редактирование карточек действующих сотрудников.
- Увольнение сотрудников с сохранением записи в базе данных.
